Interactive reference guide with clear explanations and copyable code examples for all major TypeScript concepts.

1. Primitives & Explicit Types

TypeScript allows explicitly annotating variables with number, string, boolean, and array signatures.

export const serverPort: number = 8080;
export const locationName: string = "Dayton, Ohio";
export const isOnline: boolean = true;
export const portList: number[] = [8080, 8880, 11434];

2. Interfaces & Modifiers

Define object contracts with interface. Mark immutable properties with readonly and optional fields with ?.

export interface WaterSensor {
  readonly id: number;
  location: string;
  psi: number;
  alertMessage?: string;
}

3. Generics <T>

Generics preserve exact payload types using placeholder type parameters <T>.

export interface TelemetryPacket<T> {
  timestamp: string;
  payload: T;
}

export function wrapPacket<T>(data: T): TelemetryPacket<T> {
  return { timestamp: new Date().toISOString(), payload: data };
}

4. SQLite Database Row Typing

Map raw SQLite3 query columns to strongly typed interfaces to eliminate any in backend data pipelines.

export interface SqliteNote {
  id: number;
  title: string;
  content: string;
  tags?: string;
  created_at: string;
}

export function parseRow(row: any): SqliteNote {
  return { id: row.id, title: row.title, content: row.content, created_at: row.created_at };
}

5. Async Promises & REST APIs

Wrap asynchronous fetch() operations in strongly typed Promise<T> objects.

export interface ApiResponse<T> {
  status: number;
  data: T;
}

export async function fetchNotes(): Promise<ApiResponse<string[]>> {
  return { status: 200, data: ["Note 1", "Note 2"] };
}

6. Utility Types: Pick, Omit & Partial

Derive new type variants using TypeScript's built-in Omit, Pick, and Partial utilities.

export interface UserProfile {
  id: number;
  username: string;
  passwordHash: string;
  email: string;
}

export type PublicUser = Omit<UserProfile, 'passwordHash'>;
export type ProfilePatch = Partial<UserProfile>;
